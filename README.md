# Loan-Fraud-Detection
This dataset has two files, one is transaction and another is loan application file. These 
two files can be used for separate data processing, i.e. for fraud detection at transaction 
level and loan fraud. When both these files are combined then we can predict the fraud 
at customer level.
The link to the file is https://www.kaggle.com/datasets/prajwaldongre/loan-application-and-transaction-fraud-detection?select=transactions.csv  

##Objectives   
This dataset consists of two files which have two different purposes: the transaction file 
can be used to detect fraud at transaction level, and the loan application helps to find 
the loan fraud. However, when these two files are merged, fraud risk per customer can 
be computed. Basically, this is a classification model which helps to classify whether the 
customers are under high risk, medium risk, or low risk of fraud.
